# The Map Project

> Internal codename for a GIS-based Smart Road Navigation & Live Road Intelligence System.

## Status

🟢 Planning Phase

## Current Milestone

Milestone 0 — Project Foundation

## Objective

Develop a scalable navigation platform capable of providing:

- Live Road Closures
- Dynamic Routing
- Construction Updates
- Pothole Reporting
- Flood Alerts
- Authority Dashboard
- Community Reports
- Real-Time Notifications

## Technology Stack

- Flutter
- Supabase
- PostgreSQL
- PostGIS
- GraphHopper
- OpenStreetMap
- Firebase Cloud Messaging
